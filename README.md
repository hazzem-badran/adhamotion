# 🚀 Hazem Badran - Portfolio Website

A modern, responsive portfolio website built with React, Vite, and Tailwind CSS showcasing my work as a React & React Native Developer.

## ✨ Recent Improvements (Updated)

### 🔧 Technical Enhancements
- **✅ CSS Architecture**: Migrated from mixed CSS modules to pure Tailwind CSS
- **✅ Code Quality**: Removed excessive IDs and name attributes for cleaner markup  
- **✅ Error Handling**: Added comprehensive Error Boundaries for better UX
- **✅ Component Structure**: Improved component organization and reusability
- **✅ Button System**: Unified button components with consistent styling
- **✅ Timeline Component**: Created reusable Timeline component for career/education sections

### 🎨 Design Improvements
- Modern button styles with hover effects
- Consistent color scheme using Tailwind custom colors
- Better responsive design implementation
- Cleaner component structure

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite 6
- **Styling**: Tailwind CSS 3.4
- **Routing**: React Router DOM 7
- **State Management**: Zustand 5
- **Email Service**: EmailJS
- **Icons**: FontAwesome
- **Build Tool**: Vite with optimized bundling

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📁 Project Structure

```
src/
├── components/          # Reusable UI components
│   ├── ErrorBoundary/   # Error handling
│   ├── Timeline/        # Timeline component
│   └── ...
├── pages/              # Main application pages
├── constants/          # Data and configuration
└── store/             # State management
```
